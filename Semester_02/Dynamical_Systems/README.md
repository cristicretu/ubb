# Dynamical Systems

Semester 2 · Year 1 · Maple

Differential and difference equations, linear systems, equilibria and stability, phase portraits. The lab work is done in Maple: solving ODEs with `dsolve`, eigenvalues of matrices, iterating maps and plotting orbits.

## Contents

| Folder | What it is |
| --- | --- |
| [Labs/Lab_01](Labs/Lab_01) | PDF export of a Maple worksheet: Maple basics (`evalf`, `expand`, `factor`, `simplify`, plots) |
| [Labs/Lab_03](Labs/Lab_03) | PDF export: solving first and second order linear ODEs with `dsolve`, limits of solutions |
| [Labs/Lab_04](Labs/Lab_04) | PDF export: matrices, determinant, inverse, characteristic polynomial, eigenvalues and eigenvectors |
| [Labs/Lab_06](Labs/Lab_06) | PDF export: iterating a one-dimensional map `x -> x(1-x)` and plotting the orbit |
| [Labs/Lab_Exam](Labs/Lab_Exam) | Photos of the lab test subjects (integral, eigenvalues, an IVP, the Brusselator phase plane) |
| [Practice](Practice) | Maple worksheets (`.mw`) for the labs and lab test practice, with PDF/HTML exports; `images/` holds the images used by the HTML export |
| [Exam](Exam) | Solved past exams (PDF) and photos of 2023/2024 written exam subjects |

## How to run

Open the `.mw` files in [Practice](Practice) with Maple (File > Open) and run them with Edit > Execute > Worksheet. The PDFs in `Labs/` are read-only exports of the same kind of worksheet.
